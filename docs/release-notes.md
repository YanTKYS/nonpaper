# Release Notes

## v0.1.2

ソースコードレビューで見つかった、通常業務の妨げになる不具合を修正しました。

### 修正

* 管理画面（manage.html）がまったく動作せず、「処理中にエラーが発生しました。」だけが表示されて会議の公開・下書きへの差し戻し・終了・削除・PDF登録画面への移動がいずれも行えなかった問題を修正
  * `<span id="status">` をid名のグローバル変数として参照していたが、ブラウザーの既定プロパティ `window.status`（文字列）が優先されるため、代入時に `TypeError` となり画面の初期化が中断していた
* イベント削除時にPDFが使用中で削除できなかった場合に、「管理用URLが正しくありません。」という誤った理由が表示され、主催者が対処できなかった問題を修正（時間をおいた再実行を促す案内を表示）
* PDF登録画面で、資料一覧の再取得に失敗したときのエラー表示が直後に消えてしまい、失敗に気付けなかった問題を修正
* 参加者画面で想定外の例外が起きると30秒ごとの状態確認が止まり、会議が終了しても資料を表示したままになる問題を修正
* 汎用ライブラリ lgtoolkit の `files.formatBytes()` が、単位の境界付近で「1024.0 KB」のような桁上がりしない表記を返していた計算誤りを修正（1048575 バイト → 「1.0 MB」）

### 内部の変更

* 各画面のスクリプトで、id名の暗黙のグローバル変数に依存していた要素参照を `common.js` の `element(id)` 経由へ統一（同種の不具合の再発を防止）
* 管理トークンの不一致を `ManagementTokenException`、保存領域のファイル使用中を `StorageBusyException` として区別し、ファイル操作の失敗を認証エラーとして扱わないよう修正
* 起動ログのバージョン表記をアセンブリのバージョンから取得するよう変更

## v0.1.1

コードレビュー（[docs/review/code-review-v0.1.0.md](review/code-review-v0.1.0.md)）で指摘された不具合と、通常業務で支障となる不具合を修正しました。

### 修正

* 参加者画面で30秒ごとの状態確認が行われるたびに、閲覧中の資料とページが先頭へ戻っていた問題を修正
* 参加者画面で「領域に合わせる」の後に拡大・縮小すると、表示倍率が壊れて資料を表示できなくなる問題を修正
* 参加者画面でページ番号を入力中に左右キーを押すと、意図せずページが移動する問題を修正
* 登録資料が0件の状態を経由すると、以後に登録した資料を表示できなくなる問題を修正
* 1ファイルの上限（既定100 MiB）に満たないPDFでも、サーバー既定の要求サイズ上限（30 MB前後）で予期しないエラーになる問題を修正
* 複数PDFの登録で一部が不正だった場合に、正常だったPDFだけがディスクへ残っていた問題を修正（全件を検証してから確定し、失敗時は残さない）
* 同じイベントを同時に更新すると、後の保存が先の変更を上書きしてしまう問題を修正（認証から保存までをイベント単位で排他）
* 資料の名称変更・並び替え・削除にも、登録と同じ「下書き状態のみ」の検証を適用
* イベント削除中に配信中のPDFがあると削除に失敗し、状態が「削除中」のまま残る場合があった問題を軽減（短時間の再試行）
* 会議名やURLのコピーが、HTTP接続の環境では何も起こらずに失敗していた問題を修正（代替手段と結果の表示を追加）
* イベント作成・資料登録・状態変更の連打による二重実行を防止
* 一時的な通信エラーで参加者画面が閲覧終了扱いのままになる問題を修正（復帰時に再表示）

## v0.1.0

初回リリースです。庁内ネットワークで完結する、ブラウザー型の簡易ペーパーレス会議システムを提供します。

### 主な機能

* イベント（会議）の作成、公開、下書きへの差し戻し、終了、削除
* 複数PDF資料の登録、名称・順序の変更
* 参加者向けの資料閲覧画面（資料切替、ページ移動、拡大縮小、全画面表示）
* 会議終了後、参加者画面が最大30秒以内に閲覧を終了
* イベント削除時にJSON・PDF・イベントフォルダーを一括削除

### 動作環境

* Windows Server/Windows、IISまたはASP.NET Core Kestrel
* .NET 8 SDK（配置先にはASP.NET Core Hosting Bundleまたは.NET 8 Runtime）
* 現行版のChrome、Edge、Firefox

### セキュリティ

* イベント/資料IDは128ビット乱数、管理トークンは256ビット乱数
* 管理トークンは作成時のみ表示し、保存はSHA-256ハッシュのみ
* PDFは静的領域に置かず、公開状態と所属を確認するRange対応APIから配信
* 通常の画面操作ではPDFのダウンロード・印刷を提供しない

### 制約

* SPA、データベース、外部API、CDNは使用しません
* `closed` は終端状態であり、終了した会議は再公開できません

詳細は [README.md](../README.md) および [docs/architecture.md](architecture.md) を参照してください。
